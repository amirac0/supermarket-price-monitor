# Supermarket Price Monitor

Surveille une liste de produits autour d'Eaubonne.

## Règles
- promotion explicite, ou
- prix au kg au moins 30 % sous la médiane des autres offres comparables ;
- au moins 3 autres prix valides sont requis pour la comparaison.

## État
Le moteur de comparaison, les produits et une première liste de magasins sont installés.
Les collecteurs d'enseignes restent en mode validation : aucun prix n'est inventé et les prix non vérifiables sont ignorés.

## Horaire prévu
Tous les jours à 08:00 Europe/Paris.
